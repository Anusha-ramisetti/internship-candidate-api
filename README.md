\# Internship Candidate Management System



A full-stack web application for managing internship candidates.



The system allows users to register candidates, view candidate details, update candidate information, delete candidates, search candidates, and track candidate status through a dashboard.



\## Features



\- Candidate registration

\- Candidate list

\- Candidate search

\- Candidate update

\- Candidate deletion

\- Candidate status management

\- Dashboard with candidate counts

\- Form validation

\- REST API using FastAPI

\- SQLite database

\- React frontend

\- API documentation using Swagger

\- Basic API tests



\## Technologies Used



\### Backend



\- Python

\- FastAPI

\- SQLAlchemy

\- SQLite

\- Pydantic

\- Pytest



\### Frontend



\- React.js

\- JavaScript

\- HTML

\- CSS

\- Vite
